使用前，了解这几件事。

我的文件会上传到哪里？

桌面工具在本机处理输入与文件，不需要云端账户。官网仅展示产品和读取 GitHub 发布信息，不提供文件上传。

切换语言会丢失输入吗？

不会。界面语言即时切换，工具内容保留。桌面与官网各自记住语言选择；用户输入和转换后的文档不会被自动翻译。

所有 PDF 都能准确转换吗？

扫描版 PDF、复杂排版、字体及表格可能影响结果，当前不提供 OCR；转换后请检查内容。旧式 .doc 文件不在支持范围内。

如何升级？

保存正在处理的内容并关闭旧版，下载对应平台的新版本后安装或替换。当前没有自动更新；未签名的新版本可能再次出现系统提示。
