使用前，了解这几件事。

我的文件会上传到哪里？

桌面工具在本机处理输入与文件，不需要云端账户。官网仅展示产品和读取 GitHub 发布信息，不提供文件上传。

所有 PDF 都能准确转换吗？

不保证。扫描版 PDF、复杂排版、字体及表格可能影响结果，当前不提供 OCR 扫描识别；转换后请检查内容。旧式 .doc 文件不在支持范围内。

如何升级？

保存正在处理的内容并关闭旧版，下载对应平台的新版本后安装或替换。当前没有自动更新功能，安装与升级兼容性仍在验收中。
