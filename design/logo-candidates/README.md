# TangTool Logo 候选

用户已确认使用可编辑 SVG；本组为代码原生矢量设计，未调用图片生成 API。文件均为 512×512 viewBox，外部透明留边，使用具名 g 分组，无位图、字体和外部资源。

打开 `index.html` 可并排比较 A～D，并查看 48/32/16px 和浅/深背景。可以直接从文件系统打开，不需要构建。

- A `01-folded-t.svg`：折角 T，松绿/米白/薄荷；推荐与现有官网风格配合。
- B `02-modular-t.svg`：模块 T，深蓝/浅蓝；推荐突出多工具组合。
- C `03-toolbox.svg`：随身工具箱，暖橙/奶白；语义直接。
- D `04-linked-tt.svg`：双 T 协作，紫/薄荷；字母组合。

用户最新选择 B 模块 T，已同步到 `public/tangtool.svg`、官网 `mark.svg` 及 `src-tauri/icons` 的桌面 PNG/ICO/ICNS，开发窗口品牌区与 favicon 已接入。其他候选仍保留。未做商标检索；候选不代表已获商标注册或独占使用保证。
