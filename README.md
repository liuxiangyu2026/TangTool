# TangTool

简体中文 | [English](README.en.md)

TangTool 是一款面向 Windows 和 macOS 的本地桌面工具箱，集成 22 个常用工具，涵盖数据、文档、编码、文本和图像处理。支持简体中文与英文、工具搜索与收藏、主题切换和新版本提醒，输入内容和文件在本机处理。

[访问官网](https://liuxiangyu2026.github.io/TangTool/)

## 工具

| 工具 | 功能 |
| --- | --- |
| JSON 格式化 | 格式化、压缩、校验、语法高亮、折叠与 JSONPath 查询 |
| JSON / YAML 互转 | 本地转换、校验与导出 |
| 文本脱敏 | 手机号、邮箱、身份证、银行卡及自定义规则脱敏 |
| JSON 对比 | 两侧格式化、完整字段对照、只比较 key、定位与 key 顺序对齐 |
| JSON 转 Excel | 多 Sheet 导出、递归树形数据平铺 |
| Excel / CSV 转 JSON | 选择工作表，将表格转换为 JSON |
| 文档转 Markdown | 安装独立文档组件后，批量转换 DOCX / PDF，支持排版与原始预览 |
| Word / PDF 互转 | DOCX 转 PDF 需 LibreOffice；PDF 转可编辑文字或页面图片版 DOCX，不含 OCR |
| PDF 转图片 | 按页生成 PNG / JPEG，自定义尺寸、页码范围及 ZIP 导出 |
| 密码生成器 | 使用安全随机源批量生成密码 |
| SHA 摘要 | SHA-256 / SHA-512 文本摘要 |
| URL 编码 | URL 参数编码与解码 |
| MD5 | 文本与文件摘要 |
| Base64 | 文本与文件编码、解码 |
| 时间戳 / 时区 | 秒、毫秒、ISO 日期与时区转换 |
| UUID 生成 | 批量 UUID v4，支持大小写与连字符设置 |
| Cron 解析 | Unix / 秒级 / Quartz / Spring / 宏规则说明，预览执行时间 |
| 正则调试 | 匹配位置、捕获组、替换预览与超时保护 |
| 文本整理 | 实时去空白、去重、排序、分隔符拼接及首尾引号处理 |
| 文本对比 | 逐行差异高亮，可忽略空白 |
| 二维码生成 | 本地生成 QR Code，导出 PNG / SVG |
| Logo / 图标制作 | 居中裁剪、等比留白与背景设置，多尺寸 PNG / ICO 导出 |
| 图片转换与压缩 | 批量 JPEG / PNG / WebP / BMP / ICO / GIF 互转，按格式调整质量与尺寸 |
| 颜色选择器 | 二维选色、单张图片拾色、自动配色、多种颜色编码与 216 个 Web 安全色 |
