# TangTool

TangTool 是一款面向 Windows 和 macOS 的本地桌面工具箱，目标是让常用的数据、文档和编码处理保持简单、快速并尽可能离线完成。

> 项目目前处于第一期开发阶段，功能和界面仍在持续完善。

## 第一期功能

- JSON 格式化、压缩、校验、对比以及 JSON 转 Excel
- Word、PDF 转 Markdown
- 使用安全随机源的密码生成器
- 文本和文件 MD5 摘要
- 文本和文件 Base64 编码与解码
- URL 参数编码与解码
- 可折叠侧栏、浅色/深色/跟随系统与界面字号设置
- 一级分组折叠、时间戳/时区转换、批量 UUID v4
- 正则调试（后台超时保护）、文本去重/排序、SHA-256/512 文本摘要
- 工具首页与中文/英文/拼音实时模糊搜索
- Excel/CSV 转 JSON、标准 5 段 Cron 说明与执行时间预览
- 二维码 PNG/SVG 导出、逐行文本对比、单张图片压缩
- 颜色选择器：216 色卡、HEX/RGB/RGBA/HSL/HSLA/HSV、推荐 Web 安全色及黑白字对比度参考

## 新增工具使用约定

- 启动默认进入工具首页；输入名称、英文或拼音立即筛选，也支持多个关键词。首页和侧栏共用 `src/data/tools.ts` 目录。
- 菜单分组标题可单独收起，底部“折叠到一级”一次收起所有分组；状态保存在本机。首页星标与设置页可管理工具收藏，首页收藏优先，也可只看收藏。
- 时间戳手动选秒/毫秒；日期需带时区，例如 `2026-09-14T12:00:00+08:00`。显示时区只影响结果展示，不改变瞬间。
- UUID 使用 v4 安全随机格式，每批 1～1000 条，默认 10 条，可调整大小写与连字符。
- 正则使用 JavaScript 语法，不带 `/` 分隔符，支持 `gimsuy`；最多 1000 个匹配，超过 1 秒自动停止。
- 文本按行去空白、空行和重复，再按字符排序；SHA-256/512 当前只处理文本，保留空白与换行，空文本也可计算。
- 表格反向转换支持 XLSX/XLS/UTF-8 CSV，单文件 10 MiB；首个有效行为字段名，空白/重名字段自动补齐；空单元格 null，空行跳过。原始模式保留数值和布尔值，Excel 日期为序列号，显示文本模式可保留日期格式。CSV 默认保留文本/前导零。
- 可选一个或全部 Sheet；每表最多 10000 行数据、200 列，总计 20000 行；结果超过 500 万字符或超时会拒绝，不静默截断。结果使用只读 CodeMirror 展示完整 JSON，支持行号、高亮、逐级及全部折叠/展开；复制和保存都包含完整内容。
- 首页顶部单线搜索居中约占内容区 60%，上下留白加大。工具提示在中上方显示 2 秒后自动消失，不改变页面布局。文字输入不叠加焦点轮廓，按钮仍保留键盘焦点标识。
- 多面板工具支持拖动分隔条分配宽度或高度；拖动图标与既有页面一致，也支持方向键调整。文本对比同时提供左右/上下分隔条，内容在面板内滚动，切换菜单保留比例。
- 设置新增“记住窗口大小与最大化状态”“记住各工具分栏比例”，默认开启；关闭会清除相应记录，下次启动恢复默认布局。只记布局，不保存工具内容。窗口尺寸按逻辑像素保存，恢复时限制到当前屏幕。
- 编辑器支持系统等宽/Consolas/Menlo（未安装则回退）、自动换行与 2/4/8 空格缩进；覆盖 JSON 编辑器和文本输入区。改缩进不会重写已有内容，再次格式化/对齐/表格转换时使用新宽度。
- 默认导出目录在桌面设置页选择，命名可保持原名称或追加本地日期时间；统一用于文件保存对话框和浏览器下载的建议名称，用户仍逐次确认。浏览器不能指定本机下载目录。
- Cron 仅支持标准 5 段，不含 Quartz；使用 IANA 时区与显式偏移的 ISO 起点，显示严格晚于起点的未来 10 次，不创建计划任务。日期和星期同时受限时为“或”。
- 二维码默认 M 纠错、512px、四格白边；最多 1000 UTF-8 字节，可保存 PNG/SVG。生成不会访问输入的网址，使用前请实际扫码确认。
- 文本对比每侧最多 2000 行/20 万字符；统一 CRLF/LF。忽略空白仅忽略行内空白，保留换行差异。计算在后台执行并限制时间。
- 图片首批为单张 JPEG/PNG/WebP，最多 20 MiB/2400 万像素，输出 JPEG/WebP；质量 10～100，最长边 64～8192px，不放大原图。JPEG 透明区域铺白，动画只留首帧，元数据不保留；默认以 `_compressed` 新文件名另存，结果可能比原图大。
- Word/PDF 互转本轮按用户确认暂缓；当前文档功能仍仅为 DOCX/PDF 转 Markdown。
- 颜色选择器使用二维饱和度/明度色板与竖向色相条，支持点击/拖动/方向键；保留 HEX 输入、RGB 通道及不透明度。下方完整 216 色独立竖向滚动，色块铺满卡片且附编码，点击恢复不透明。Web 安全色不是无障碍保证。
- 半透明颜色的文字对比度按所选白/黑底合成后计算；普通文字 AA 阈值 4.5:1，仅作颜色参考。HEX/RGB/HSL 不含透明度，HSV 不是 CSS 函数。

- Tauri 2
- Vue 3 + TypeScript + Vite
- Rust
- Pinia + Vue Router
- GitHub Actions

## 本地开发

请先安装 Node.js LTS、Rust 和对应平台的 Tauri 系统依赖。

```powershell
npm install
npm run tauri dev
```

检查前端类型并构建生产资源：

```powershell
npm run build
```

## 文档转换与完整安装包

开发模式的 DOCX/PDF 转换需要项目根目录 `.venv`，请保留已有环境。完整安装包使用独立 sidecar，构建步骤及 Windows/macOS 命令见 [sidecar/README.md](sidecar/README.md)。

```bash
npm run sidecar:build
npm run desktop:build
```

完整包随应用携带 Python、MarkItDown 和格式依赖；最终用户无需手动安装它们。当前只支持 DOCX/PDF，不支持 `.doc`，无需 LibreOffice。Windows/Intel macOS 真机验收及签名、公证仍在后续发布任务中。

## 隐私原则

TangTool 默认在本机处理输入内容和文件。第一期不设计云端账户，也不上传用户文件。

外观设置仅保存在本机，不保存工具输入和生成的密码；工具输入在菜单切换时保留，关闭应用后清空。版本页由用户点击后打开 GitHub，不自动联网升级。
