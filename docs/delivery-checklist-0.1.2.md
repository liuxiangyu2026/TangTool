## 使用与待验边界

- 用户需手动安装一次 v0.1.2；v0.1.1 没有更新检查功能。之后默认启动及使用期间每6小时检查，侧栏显示新版标记，版本页支持手动检查、说明和下载。设置可关闭自动检查或仅接收正式版；不自动安装、不关闭工具。
- Windows 用户仍需确认运行中任务栏图标。若已有固定快捷方式缓存旧图标，退出旧版、取消固定，再从开始菜单启动新版并重新固定即可。
- Windows 安装页 WebView2 重检、组件勾选分支、独立组件安装卸载，macOS 系统 Installer 安装后重新检测，以及干净机器、升级卸载等仍按 [0.1.1 交付表](delivery-checklist-0.1.1.md) 补齐，不能把静态检查记为真机交互通过。
