# 图片工具（工作区未发布）

## 图片转换与压缩

保留原路由 `/image/compress`，兼容原来的收藏和页面缓存。支持追加去重、独立删除及最多50张批量处理，输入和结果各限200 MiB；逐张转换，单项失败继续，任务可停止。单张另存，多张结果可打包ZIP，重名自动编号；任务与导出期间锁定相关控件。支持 JPEG、PNG、WebP、BMP、ICO、GIF 输入与输出，不支持 HEIC。处理在本机进行，文件上限20 MiB、2400万像素。

- 默认保持原尺寸；取消后按最长边等比缩小，不放大原图。
- JPEG、WebP 可调有损质量；PNG 不提供无效的质量滑块。
- JPEG、24位BMP铺白底；PNG、WebP、ICO保留透明。
- GIF输出单帧、最多256色，透明度低于128视为透明，其余视为不透明；不保留动画。使用固定版本 `gifenc@1.0.3`（MIT）在Worker中编码，20秒超时或更换输入时终止。组件随应用打包，无需用户额外安装。
- ICO读取最大尺寸图像，支持PNG与传统DIB内容。输出16/24/32/48/64/128/256px中的单个尺寸，图片居中等比缩小，外围透明留白；多尺寸ICO请使用Logo工具。
- 输出可能比原图大，仍允许另存。保存后缀依据真实输出格式；保存前检查预览，不保留元数据。
- 切换工具保留原图和结果，仅释放可重建的预览URL；改变选项使旧结果失效，迟到结果不能覆盖新输入。

GIF库说明：[gifenc](https://github.com/mattdesl/gifenc)。

## Logo / 图标制作

独立路由 `/image/logo`，JPEG/PNG/WebP输入。支持完整图片等比留白或正方形居中裁剪、0～40%四周留白、透明或自定义背景色。

PNG支持16～1024px常用尺寸，多张打包ZIP；ICO包含所选的16～256px尺寸。透明底不自动抠除原图背景。小图可能被放大，应检查预览。暂不输出macOS ICNS。

## 图片拾色与自动配色

颜色选择器仅支持单张图片拾色，最多2400万像素、20 MiB。无已选图片时“图片拾色”打开单选文件框；已有图片时恢复原来的图片和颜色，不重复选择文件。区域内“更换图片”替换当前图片，并清空上一张图片的拾色记录；新图无效时保留原图及记录。图片右上角关闭按钮移除当前图片。“收起拾色”只隐藏区域，保留文件和手动拾色记录；没有吸管或复制配色按钮。

当前图片持续显示，自动配色和手动拾色在同一行显示。默认自动配色8色，可选4～16色；128px缩小采样、alpha加权聚类，忽略完全透明像素，返回HEX和估算占比。手动拾色追加到当前图片，按RGBA去重；修改自动配色数量不清空手动记录。点击颜色应用到主选色器，通过原有RGBA/HEX8按钮复制当前颜色。颜色行横向滚动，不换行；完全透明图片允许手动拾色。

图片初次打开按宽高适应预览，初始高度上限随窗口调整、最高400px，大图不直接按原始大小展开；支持1%～400%手动缩放、原始大小、适应预览和适应宽度。手动选择原始大小或适应宽度后，不再自动限制图片高度；“适应预览”恢复初始模式。复制颜色工具栏固定可见，下方拾色与选色区域整体竖向滚动；放大后图片区域可以横向滚动。预览仅绘制可见区域及少量边缘，画布最多800万像素、单边8192px，避免极长图或放大后分配巨幅画布。裁切边界对齐原图像素，原始大小保持清晰。

图片使用吸管光标和像素放大镜定位，点击拾取原图RGBA（含alpha），不读取缩放后的混合色。指针事件保持小数精度，避免悬停和点击颜色不一致。方向键移动1像素、Shift加速到10像素，Enter/空格确认，Escape只隐藏放大镜、不隐藏图片。动画只取首帧。隐藏区域、删除图片或离开页面时释放ImageBitmap和画布，恢复按需重建。

浏览器已验证图片常驻、单选文件、更换后只显示新图、单行颜色、自动/手动配色及去重、修改色数保留记录、收起恢复不弹文件框、右上角删除、透明图、浅深主题、英文界面及900px窗口。另已验证3000px/40000px高图、缩放/原始大小/适应宽度、固定工具栏以下整体滚动、横向滚动后的末端单像素拾色、预览画布上限与可见像素。Web安全色区域根据实际卡片高度、行间距、内边距及标题高度动态保留三整行；已检查三档宽度、三档字号、浅深主题共18种组合，仍保留全部216色与独立滚动。高图初始预览、窗口高度适配、手动缩放及恢复初始模式通过验证。没有新增永久测试文件。
