# 六项日常工具扩展（工作区未发布）

2026-10-13新增两个独立工具，总计24个；其他四项在原工具内扩展。全部本地处理，切换菜单/语言保留输入和结果，刷新或关闭后清空，不写入持久化设置。无新增运行时插件。

## JSON / YAML 互转

路由`/json/yaml`，位于JSON/表格组。支持JSON与YAML 1.2双向转换、示例、UTF-8文件导入、复制和导出，缩进沿用编辑器偏好。

使用`yaml@2.9.1`，在5秒超时Worker中处理。文本最多200万字符，导入文件最多2 MiB，展开后最多10万节点/200层。保留字符串/布尔/null/数组/对象语义；YAML注释和排版不保留。重复键、多文档、未知标签、非字符串键、循环别名、非有限数及不安全整数报错，不静默转成null或字符串。普通别名最多展开100次，禁用YAML 1.1合并键语义。

## 文本脱敏

路由`/text/redact`，位于文本组。规则分别开关，默认包括手机号、邮箱、中国大陆15/18位身份证及银行卡号。首尾保留规则显示在界面，银行卡支持连续数字或4位空格/短横线分组，手机号支持86前缀。

按原文位置收集匹配，优先处理邮箱/身份证，避免重叠数字重复脱敏。仅按格式识别，不保证识别所有敏感信息，也不验证身份证/银行卡真实性；预览后再分享。原文不改变，可复制或导出结果。

自定义正则在默认规则后执行，固定`gu`，支持数字和命名捕获组。输入最多10万字符，正则和替换内容各2000字符，结果最多200万字符。3秒Worker超时可终止灾难性回溯。

## JSONPath 查询

保留JSON格式化路由和按钮顺序，在编辑器上方新增查询行。支持字段、通配符、递归、负索引、切片、比较和逻辑筛选。示例：`$.tools[?@.enabled == true].name`。

值结果总是数组，另可显示规范路径和值；不覆盖原JSON。编辑原文或表达式会使旧结果失效。使用`jsonpath-js@0.3.1`的语法树解释器，不执行JavaScript脚本或函数调用。解析后的对象去掉原型，`constructor`等仅匹配实际JSON字段。

JSON最多200万字符，表达式最多2000字符，结果最多5000项及400万字符（值与路径合计）；3秒Worker超时。切换语言不翻译用户数据。

## 正则替换预览

保留原匹配工具，新增替换内容、预览及复制结果。使用JavaScript替换语义：无`g`只替换首个匹配，有`g`替换全部；支持`$1`、`$<name>`、`$&`、`$$`及前后文引用。零长度匹配按Unicode码点前进，原文不改变。

匹配和替换均在现有1秒超时Worker中运行；逐个匹配并限制输出拼接，避免积累巨量捕获组或展开前后文。最多200万输出字符，改变输入/规则清除旧结果，停止、超时与迟到响应不会覆盖新任务。

## 批量图片与图片配色

详见[图片工具](image-tools.md)。批量最多50张、输入和结果各200 MiB，顺序处理并隔离失败；只为当前选中图片创建预览URL，离开页面释放URL，原文件和结果保留。支持追加去重、单项删除、停止、单张另存和ZIP导出；参数修改使旧结果失效，任务/导出期间锁定相关操作。ZIP文件名过滤路径字符，大小写不敏感去重并自动编号。

颜色选择器仅支持单张图片拾色，最多2400万像素、20 MiB。图片持续显示，自动配色和手动拾色单行去重；“更换图片”替换当前图片及其拾色记录，无效新图保留原图；右上角关闭移除当前图片，收起只隐藏并保留记录，再次点击图片拾色恢复。自动配色默认8色、可选4～16色，使用128px缩小采样和alpha加权聚类，占比为估算；完全透明图仍允许手动拾色。动画只读首帧。初始按宽高适应预览，最高400px高；支持缩放、原始大小、适应预览和适应宽度；顶部复制工具栏以下整体竖向滚动，图片放大后可横向滚动。预览只绘制可见区域，拾色读原图像素。方向键/Enter拾色、Escape只隐藏放大镜。点击色块应用到现有选色器，通过原有RGBA/HEX8按钮复制当前颜色。
